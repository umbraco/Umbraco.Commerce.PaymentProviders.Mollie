# Upgrade to Umbraco 19

From Umbraco Commerce `[18.0.0, 18.999.999)` (CMS 18) to Umbraco Commerce `19.0.0-beta.1` (CMS `19.0.0-beta1`, tag `release-19.0.0-beta1`).
Branch `v19/topic/cms-19-upgrade` → PR into `release/19.0.0`, both cut from `main` (`7519d70`).

**Targets CMS release:** `release-19.0.0-beta1`, via Umbraco Commerce `19.0.0-beta.1` (MyGet `umbracoprereleases`). The package's own version is `19.0.0-beta.1`.

The package depends on `Umbraco.Commerce.Core`, `Mollie.Api` and `Microsoft.AspNetCore.WebUtilities`, never on `Umbraco.Cms.*` directly, so the CMS breaking changes reach it only through Commerce. Commerce's own v19 inventory (Core repo, `docs/upgrades/v19.md`) is the source for those; the Stripe provider's v19 upgrade is the reference run.

## Tasks

Each task ends in a green build.

- [ ] 1. Bump to .NET 11, the pinned SDK, Umbraco.Commerce.Core 19.0.0-beta.1 and WebUtilities 11; fix what no longer compiles.
- [ ] 2. Mollie.Api 4 → 5.1: keep the exception flow with `EnsureSuccess()`, keep v4's amount rounding, format VAT rates; unit tests for the payment request body, amount rounding, VAT rate and error handling with a stub HTTP handler.
- [ ] 3. Remove the `mollieOnetime*` localization keys scheduled for removal in v17.
- [ ] 4. Tests in CI: run the test project in the pipeline (`run_tests: skip`).
- [ ] 5. Compatibility markers: version `19.0.0-beta.1`; package validation off, baseline 19.0.0 commented out.
